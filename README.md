# Odin Recipes

A simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

The website features a homepage with links to three different recipes. Each recipe has its own page with a picture and instructions.

## Built With

- HTML

## What I Learned

- Creating and organizing HTML pages
- Working with links and images
- Using relative file paths
- Structuring a basic website
